One word for the whole internet, entered in make.fun's "The Internet in One
Word" bounty. The word is **skibidi**: the internet is a place where a nonsense
word can travel further than any sentence ever written.

The program writes that one word to `/output/entry.txt`, the only file the
harness reads.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

Locally, `MAKEFUN_OUTPUT_DIR` stands in for `/output`.
